# SEASnet Setup Guide

A step-by-step guide for new UCLA CS/CSE students (CS 31, 32, 33, 35L) to get set up on the UCLA Samueli SEASnet Linux servers.

**Download:** [SEASnet_Setup_Guide.pdf](SEASnet_Setup_Guide.pdf) (11 pages)

## What it covers

- Activating your SEASnet account and changing your password
- Connecting off campus with the UCLA Campus VPN
- Choosing a host (`lnxsrv.seas.ucla.edu`) and staying under the 3 GB home directory quota
- **Windows:** PuTTY, PowerShell, WinSCP, `scp`, X11, VS Code Remote-SSH
- **macOS:** Terminal, `scp`/`sftp`, X11 via XQuartz, VS Code Remote-SSH
- **Linux:** OpenSSH, `scp`/`sftp`/`rsync`, X11, VS Code Remote-SSH
- Troubleshooting table and a command cheat sheet

## Accuracy

Account, VPN, host, quota, PuTTY, and SSH/SFTP details were checked against official SEASnet and UCLA Digital & Technology Solutions pages on September 29, 2026 (sources are listed on the last page of the PDF). The WinSCP, macOS, Linux, and VS Code Remote-SSH sections are practical advice, not official SEASnet documentation. Server names, quotas, and VPN clients can change, so check the official pages if something no longer matches.

This is an unofficial, student-made guide and is not affiliated with SEASnet or UCLA.
